# MOBA 2017 Digital Election Management System

A secure digital election platform for **MOBA 2017** (Mfantsipim Old Boys
Association, 2017 year group), developed by **Sunleon Router Enterprise**.

Approved members receive individual credentials by email, review the
candidates for each executive position, and cast one secret ballot during the
official voting window. The System Administrator runs the election; the
Electoral Committee observes everything in read-only mode; nobody — including
administrators — can see how an individual member voted.
